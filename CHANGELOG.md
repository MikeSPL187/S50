# Журнал изменений

## 2026-11-01 — исправления по третьей рецензии

* `90-restore-stock.sh`: проверки модели/CID только в загрузчике (в AOSP fastbootd нет `sku`/`cid`); запуск из
  fastbootd → переход в загрузчик без записи; откат только при известном состоянии (adb-сверка или журнал
  эксперимента); `slot-successful:_b=yes` — запрет без обхода; флаг переименован в `--accept-unverified-state`.
* `40-flash-experimental-vendor-dlkm.sh`: журнал `EXPERIMENT-STATE.txt` с ожидаемым `vbmeta.digest` эксперимента.

## 2026-11-01 — исправления по второй рецензии

* Маркер сверки `DEVICE-MATCH.txt`: удаляется в начале каждого запуска `20`, создаётся только при полном успехе,
  содержит проверенные значения, время, хэши эталона и копии; режим `20 --recheck-only`.
* `30-preflash-gate.sh`: проверка содержимого и возраста маркера (≤ 120 мин); размер образа ≠ стоковому — СТОП;
  `teleu` обязателен; `securestate` locked — СТОП; привязка к сборке через `version-bootloader`.
* `90-restore-stock.sh`: запрет отката при иной сборке (в т. ч. после OTA); `--accept-unverified-build` только
  для нечитаемой версии.
* Эталонные значения и хэши вынесены в `scripts/device/expected/`; `gvm` читает многочастные getvar Motorola.
* Уточнены формулировки силы признаков соответствия (06, вывод `00`/`20`); `oem config cmdl` не рекомендуется.

## 2026-11-01 — исправления по внешней рецензии

* `90-restore-stock.sh`: останов при `current-slot≠a`; режим `--set-active-a` для случая автопереключения на
  непригодный слот B; запуск из загрузчика или fastbootd; без автозагрузки системы.
* `40-flash-experimental-vendor-dlkm.sh`: после записи возврат в загрузчик и загрузка только по фразе `BOOT`.
* `30-preflash-gate.sh`: `slot-successful:_a=yes` обязателен; вывод состояния обоих слотов.
* Общие функции fastboot вынесены в `scripts/device/lib-fastboot.sh`.
* Исправлена переоценка в документации: при ORANGE совпадение `vbmeta.digest` не доказывает содержимое
  `boot`/`vendor_boot`; сверка дополнена `/proc/version`, `ro.bootimage.build.date.utc`, `ro.boot.veritymode`
  (`tools/bootimg_kernel.py`, `00`, `20`).
* Диагностика механизма загрузки модулей MTK (путь к A/B без root через `modules.options`).

## 2026-11-01 — этап 1 (сборка W1UI36H.39-25-11-4)

* Найдены исходники точной сборки; доказано соответствие ядра (GKI android14-6.1-2025-12_r29) и vendor-модулей.
* Воспроизводимая сборка GKI (идентичные релиз, размер Image, раскладка секций, KMI) и модулей MTK
  (код побайтно = сток).
* Патчи `sugov_ext`: 0001 (лимиты до rate limit), 0002 (переключатель iowait-буста, по умолчанию сток).
* Инструменты: KMI-gate, сравнение модулей, чтение super/EROFS/vbmeta, статистика A/B.
* Скрипты Steam Deck: диагностика, замеры, резервная копия с доказательством соответствия, предполётная
  проверка, установка (ручная), откат.
* Экспериментальный артефакт `vendor_dlkm` + vbmeta проверен офлайн; на телефон не устанавливался.
